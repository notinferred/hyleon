# Backlog

Ideas that aren't on the [roadmap](ROADMAP.md) yet. Nothing here is committed to.

- **Hyleon in the customer's CI.** Run `hyleon check` in a customer's own pipeline, so a drawing set is gated the way tests gate code.
- **A pack authoring view.** Write and test a company pack in the app, without editing TOML by hand.
- **QR codes on panels and devices** that open the as-built record for that tag.
- **Label printing.** Send tags, wire markers and nameplates to label printers.
- **Imports.** Read network inventory from NetBox, and controller tag lists from SCADA exports, into the model.
- **Procurement.** Turn a BOM into requests for quotes.
- **Site voice notes**, transcribed into markups. The person confirms them, because the transcript is AI-inferred.
- **Other languages** for the UI and the generated sheets.
