# Printing and export, version 1

**Status: planned** (D-029, D-030).

## Scale

- Every sheet has a true scale (or is marked "not to scale") and a design paper size.
- Whatever paper it's printed on, the sheet states the scale it was printed at and carries a graphic scale bar, so measurements stay honest.

## Print modes

| Mode | What it does |
|---|---|
| True size | 1:1 on the sheet's own paper size |
| Fit to paper | Scaled to any paper, with the effective scale printed on the sheet |
| Tiled | A large sheet split across small pages (Letter, A4, 11×17), with overlaps, cut marks and a map of the tiles |
| Half-size set | For example 22×34 printed at 11×17, marked as half scale |
| Print set | The whole set or a selection at once, in sheet order with the index: to one bookmarked PDF, or straight to a printer or plotter |

## Styles

- Plot styles come from the owner profile: line weights per purpose, and colour, grayscale or monochrome.
- The "PRELIMINARY, NOT FOR CONSTRUCTION" watermark stays until a revision is issued.

## PDFs

- PDF/A-2u, with bookmarks and clickable cross-references.
- Optional layers per discipline.
- Tagged for accessibility (PDF/UA) where the tooling allows.

## Branding

The company profile ([owner.md](owner.md), "Company profile") supplies the logo, company details, colours and fonts. Fonts must be licensed for embedding.
